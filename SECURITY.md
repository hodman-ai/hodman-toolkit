# Security policy

Supported release line: the latest published Toolkit release (including the current release candidate during review). Do not post sensitive vulnerability details or credentials in public issues.

Report privately through GitHub's **Report a vulnerability** flow on the repository Security tab, **if private vulnerability reporting is enabled**. If it is not available, request a private reporting route from the repository maintainers without including exploit details in a public issue. There is no verified security email for this repository; do not assume a public issue is private. Maintainers will acknowledge and coordinate remediation; no response-time guarantee is implied.
